# CORE PRODUCT VISION

I am building a Health-Aware Todo Application.

This is NOT a generic productivity app.

The core problem:

Some users (e.g., chronic illness patients such as chronic pancreatitis) experience recurring health flare-up days during which tasks cannot realistically be completed.

Traditional todo apps mark those days as:
- Failed
- Missed
- Broken streak

This creates psychological penalty.

The system I want must:
Track these days intelligently.
Classify them.
Analyze them.
Never penalize them.

# PACE: A Todo + Health Context Engine.

## Day Classification
- Mark a day as Flare-up day
- Low energy day
- High pain day
- Medication-heavy day

## Health Tracking
- Pain level (scale-based input)
- Fatigue level
- Mood
- Calorie intake
- Food log
- Medicine schedule
- Weight tracking

## Filtering
- Filter days by health state
- Filter by pain level range
- Filter by productivity under health constraint

## Reporting
- 3-month analytics (Free tier)
- 6-month + yearly analytics (Paid tier)

# DIFFERENTIATING FACTOR OF PACE

Pace must:

- Never penalize health-related non-completion
- Adapt task expectations dynamically based on health state
- Provide contextual analytics such as:
  - “On high pain days, completion drops by X%”
  - “Low calorie intake correlates with low productivity”
- Implement a measurable productivity fairness model

Avoid gamification patterns that create guilt.
